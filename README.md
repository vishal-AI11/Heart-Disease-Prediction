❤️ Heart Disease Prediction using Machine Learning
Project Overview

This project predicts whether a patient is likely to have heart disease based on medical attributes using Machine Learning techniques.

The project follows a complete machine learning pipeline, including:

Data Collection and Merging
Data Cleaning
Exploratory Data Analysis (EDA)
Outlier and Skewness Handling
Feature Encoding
Model Training
Model Evaluation
Hyperparameter Tuning
Cross Validation
Feature Importance Analysis
Model Serialization using Pickle
Streamlit Deployment
